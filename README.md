# AI Developer Portfolio

**Live site:** [www.aleksandr.website](https://www.aleksandr.website)

Personal portfolio for an **AI Creative Developer / Vibe Coder** — built to showcase products, prototypes and automation systems developed with LLMs as a full engineering partner (architecture, implementation, review, docs).

## What it shows

- **Projects** — real products shipped with AI-assisted engineering: a multi-tenant SaaS ERP, a global VPN infrastructure control plane, an Avito lead-automation bot, and the AI-first development workflow behind them.
- **AI Workflow** — the repeatable loop from idea → prompt engineering → AI generation → human review → iteration → production.
- **AI Experiments** — smaller explorations: LLM agents, automation workflows, AI-generated interfaces, rapid prototyping.

## Stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS**
- **Framer Motion** — scroll animations, interactions, typewriter effect
- Fully **bilingual** (RU / EN) with instant language switching
- Deployed as a static export behind **Nginx** with **Let's Encrypt** SSL

## Design

Minimal, technology-forward aesthetic inspired by Linear / Vercel / Anthropic — dark UI, glassmorphism, gradient accents, and an interactive "AI IDE" hero scene.
